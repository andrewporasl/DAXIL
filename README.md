# DAXIL

DAXIL is a desktop video utility for trimming, compressing, and exporting local media files. It is built with Electron, React, TypeScript, and FFmpeg, and is designed for private local workflows: files stay on the user machine and are not uploaded to a service.

Release builds include bundled `ffmpeg` and `ffprobe` binaries. End users do not need Node.js, FFmpeg, FFprobe, or a command-line setup to use the packaged application.

## Product Scope

DAXIL focuses on fast local media handoff:

- Load local video files through the add target, drag and drop, or the header open action.
- Preview video in-app with playback controls, timeline scrubbing, and generated thumbnails.
- Set trim ranges with timeline handles or direct in/out controls.
- Export to `MP4`, muted `MP4`, `MP3`, or `GIF`.
- Apply compression presets from source quality through aggressive reduction.
- Estimate output size before rendering.
- Track export progress and inspect FFmpeg logs.
- Open another file in the same window or start a separate editor window.
- Choose dark or light visual themes from the header theme selector.
- Configure default output folder and optional custom FFmpeg/FFprobe paths.

## Basic Workflow

1. Open a local media file.
2. Preview and scrub the video.
3. Adjust the trim range with the timeline handles or in/out controls.
4. Choose a compression preset and output format.
5. Select the output folder.
6. Export the file and open the result folder when complete.

Use `New Window` when working on a second clip without replacing the current source.

## Requirements

## Development

Install dependencies and start the Electron development app:

```bash
npm install
npm run dev
```

Build the app bundles:

```bash
npm run build
```

Run TypeScript validation:

```bash
npm run lint
```

## Packaging

Generate release icons:

```bash
npm run release:assets
```

Package for the current platform:

```bash
npm run package
```

Package specific targets:

```bash
npm run package:mac
npm run package:mac:x64
npm run package:mac:arm64
npm run package:win
npm run package:linux
```

Packaged artifacts are written to `dist/`.

## Implementation Notes

- Local preview uses a custom `safe-file://` protocol so Electron can stream local files reliably, including absolute paths and filenames with spaces.
- Thumbnail strips are generated through FFmpeg after metadata loads.
- Compression is bitrate-targeted based on the selected preset and the effective trimmed duration.
- GIF export uses a two-pass palette workflow for cleaner output.
- MP4 export uses stream copy when no trim, mute, or compression change is required.
- Trimmed MP4 output is re-encoded to produce stable clipped files.
- Theme selection is stored in `localStorage` and applies CSS variables at the app shell.

## Privacy

DAXIL is a local desktop application. It does not upload media files, require accounts, or send video content to a hosted service.

## Code Signing

Current public builds are unsigned. macOS may display the standard first-run warning for unsigned applications. Users can open the app through the macOS contextual `Open` command or through `System Settings > Privacy & Security`.
