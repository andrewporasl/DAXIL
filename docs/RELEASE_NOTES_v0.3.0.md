# DAXIL v0.3.0 Release Notes

DAXIL is now a small multi-track editor rather than a trim-and-compress utility. Media pool on the left, preview in the middle, inspector on the right, and a free-form timeline across the bottom.

## New

- **Free-form multi-track timeline.** Video tracks V1…Vn and audio tracks A1…An. Place clips anywhere, leave gaps, drag clips in time and between tracks, snap to neighbouring clips and the playhead (Alt bypasses). Higher video tracks draw over lower ones; drag a layer in the preview to position it, resize from the corner, set opacity. Hide a video track or mute an audio track from its header.
- **Paste a link.** Drop a YouTube, X/Twitter or other video URL into the link box (or Ctrl+V anywhere). It is downloaded with yt-dlp, saved as `clip1.mp4`, `clip2.mp4`, … in your download folder, added to the pool and appended to V1. The **GIF** button turns a link straight into a GIF with no editing step.
- **Media pool.** Thumbnail grid with multi-select, drag several assets at once, rename (double-click, F2 or right-click), and remove — removing an asset that is on the timeline asks first and takes its clips with it in one undo step.
- **Drop files anywhere.** Every dropped file is imported; drop onto the timeline to place it on a track at that time.
- **Editing.** Split everything under the playhead, trim handles that keep the out point fixed, rubber-band selection across tracks, group drags, arrow-key nudging, ↑/↓ to change track, Ctrl+D duplicate, Home/End.
- **Zoom that stays anchored.** Ctrl+wheel and pinch zoom around the cursor; the buttons zoom around the playhead; smooth steps; time ruler with scrubbing.
- **Inspector** holds only controls: Transform (selected video clip), Crop, Compression, Deliver.
- **Settings:** yt-dlp path override, Update button and download folder.

## Changed

- Export composites every track over black and mixes every sounding clip (video clips carry their own sound), then applies crop, speed and the GIF palette. "Check size" uses the same graph, so it is exact.
- Playback is driven by one clock with each clip as its own layer, so stacks and gaps preview as they export.
- The README was rewritten around the new workflow, with screenshots generated by `npm run screenshots`.

## Smaller installer

- The Windows build ships only the Windows ffprobe (the previous build shipped every platform's), keeps the en-US locale only and uses maximum compression. The unpacked app went from about 706 MB to about 390 MB.
- yt-dlp is not bundled. It is fetched from GitHub the first time you paste a link, into the app-data folder, and can be pointed at your own copy in Settings.

## Privacy

Your media never leaves your machine. The only network activity is fetching yt-dlp on first use (or Update) and the links you choose to paste, which yt-dlp downloads directly from the site. There are no accounts, no telemetry and no history of what you download.

## Upgrade Notes

Projects are per session, so nothing migrates. Settings are preserved; two new settings (yt-dlp path, download folder) get defaults. Builds remain unsigned; see [INSTALLATION.md](INSTALLATION.md) for first-launch prompts.
